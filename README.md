# McDonald's Website

Autonomous Website Engineering project.

## Current progress

The active release candidate is being developed on [`aeos/mcdonalds-release-candidate`](https://github.com/teyyara/mcdonalds/tree/aeos/mcdonalds-release-candidate).

Review it in [Pull Request #1](https://github.com/teyyara/mcdonalds/pull/1).

The candidate currently includes the responsive site, menu, deals, rewards demo, restaurant locator, cart and demo checkout, plus the research and validation evidence package.

**Important:** `main` is intentionally kept as the stable handoff branch until runtime certification is green. The candidate must not be treated as a production McDonald's site or live ordering system.
